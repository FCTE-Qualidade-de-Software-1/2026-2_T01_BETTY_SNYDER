Este repositório reúne a documentação desenvolvida durante a disciplina **Qualidade de Software** da Universidade de Brasília (UnB).

Este projeto tem como objetivo avaliar **a qualidade do software Anki** a partir de métricas de avaliação de qualidade de software.

O Anki é um software de código aberto para estudo com cartões de memorização (flashcards) e repetição espaçada
